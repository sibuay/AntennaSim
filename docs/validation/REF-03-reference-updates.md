## Implemented behavior

The [REF-03 contract](../methods/REF-03-reference-update-contract.md) was recorded
before implementation under fixed FND-03 equations and FND-04 thresholds.
[vacuum.hpp](../../include/antennasim/vacuum.hpp) and
[vacuum.cpp](../../src/vacuum.cpp) add pinned vacuum constants, validated CFL
selection, native field timestamps, and the owned source-free ReferenceStepper.
[Internal kernels](../../include/antennasim/detail/vacuum_kernel.hpp) expose
the same local curl/family routines used by the stepper to structural tests.

Each step completes H before E. It updates all H samples, skips exactly the
tangential E walls, and increments state only after successful completion.
Initialization explicitly copies finite, wall-compatible, screened solenoidal
E/H data; external initialization edits cannot change an active simulation.
Initial divergence screening uses the documented S08 roundoff allowance and
does not repair data or establish physical accuracy.

Invalid q/dt and strict CFL violations fail explicitly. Derived coefficient,
half-step, and timestamp representability failures are rejected. A nonfinite
update gives state/component/index, makes the stepper terminally failed, and
prevents subsequent field/time accessor use. Prior borrowed views cannot be
revoked by C++; callers must discard them after any step exception. No rollback
copy or successful result artifact is produced. These are core-library rules;
emitted result/run metadata belongs to REF-04.

The CLI remains help/version only and rejects simulation requests. Its help
sentence now says simulation commands are unavailable, replacing the obsolete
claim that no solver exists. The help regression was updated accordingly; its
version/unsupported-request tests are unchanged. No simulation CLI was added.

`--write` intentionally regenerates it.

## Review, limits, and handoff

Source review checked curl signs and axes, bounds before backward subtraction,
all-H-before-E ordering, exact wall preservation, initial copy/ownership,
strict CFL rather than clamping, and terminal partial-step failures. The
independent tests check local algebra and two complete steps; this is evidence
for the implementation, not continuum propagation or antenna accuracy.

evidence (REF-01 through REF-03), so C02 is complete. C03 has reference updates
but still needs sources, probes, run configuration, and CLI; it remains in
