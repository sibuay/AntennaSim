## Findings

### R1 / P2 — V04-C accepts the first deposit in the wrong component

`scripts/analyze_closed_benchmarks.py:555–562` sorts the three electric region
maxima before checking the first deposit. This loses the component identity:
an Ex or Ey deposit passes the requirement for the fixed Ez source. The C2/C3
probe reduction at lines 660–661 checks only finiteness, so the existing source
probe cannot detect the wrong first deposit either. Region maxima also cannot
establish that exactly one edge, or the prescribed edge, was driven.

Reproduction using copies of the actual retained C2/C3 records: at state 1,
swap the Ex and Ez maxima both globally and in the live region, and set the
recorded Ez probe values to zero. Leave all later states and metadata unchanged.
Both the structural artifact audit and the complete PEC-suite reduction return
`pass`; both driven cases have empty failure lists. Original evidence was not
modified. The reproduction is retained at
`build/evidence/MAT-02/review-faults.py`, with modified copies and results in
`build/evidence/MAT-02/review-wrong-component/`.

Recommended correction: require the deposit in Ez explicitly, require Ex, Ey
and all H maxima to be zero, and check the existing native Ez source probe at
the prescribed index and state 1 against the signed value `-dt*g_0/epsilon0`.
Add wrong-component, wrong-source-location and wrong-sign fault cases. Clarify
the specification's claim about the driven edge to match what the available
observables can prove. Preserve the current tolerance and retained measurements.

Status: **fixed** as recommended, under MAT-01 specification revision 1.3 and
D021. The retained measurements and tolerances are unchanged.

### R2 / P2 — Cavity metadata records the opposite initial H sign

`benchmarks/closed.cpp:194` emits
`H=-C E_s/(mu0 Omega) sin(omega_d dt/2) at -dt/2` into both
`configuration.json` and `metadata.json` for every mode case. The initializer
at lines 397–400 actually uses the positive coefficient. The positive sign is
the specified one: `H_s=-C E_s/(mu0 Omega)` and
`H^(-1/2)=-H_s sin(omega_d dt/2)`.

This is a metadata defect, not a demonstrated field-update defect. Reconstructing
the initial condition from the emitted description reverses its magnetic field
and breaks the intended discrete eigenmode. Correct the description and cover
its agreement with the convention in the artifact audit; record the historical
metadata typo without silently rewriting the original raw evidence.

Status: **fixed** as recommended, under D021. The retained raw evidence was not
rewritten.

### R3 / P2 — Missing prescribed probe records are accepted as measured zeros

`scripts/analyze_closed_benchmarks.py:656-659` uses
`samples.get((state, index), 0.0)` for the required zero-valued probe samples.
Consequently an absent measurement satisfies the requirement. The structural
audit at line 234 checks only that the number of rows is constant across
states, not that each state contains the prescribed set of probes. Removing
an entire probe therefore evades both checks.

Reproduction: copy `build/evidence/MAT-02/run1/pec`; for each of
`pec-c2-inside` and `pec-c3-outside`, keep only `probes.csv` rows whose index
equals `metadata.json`'s `source_index`. Leave all metadata, diagnostics and
other cases unchanged. This removes 4,097 rows per case, including the
secondary probe's required state-0/state-1 measurements. Both cases still
have `status: pass` and empty failure lists; `audit_closed` succeeds, and
`analyze_suite_pec` passes the complete five-case suite with the original
cavity references. Thus a run that silently stops recording the second probe
can be accepted as complete under revision 1.3.

The executable reproduction is retained at
`build/evidence/MAT-02/recheck-probe-completeness.py`; copied artifacts and
`result.json` are in `build/evidence/MAT-02/signoff-missing-probe/`. It touches
no original evidence. Its core mutation is:

```python
kept = [row for row in probes
        if tuple(int(row[k]) for k in "ijk") == tuple(meta["source_index"])]
```

Recommended correction: derive the expected C2/C3 probe indices from the
fixed fixture, require exactly that set of unique `(component, index)` records
at every state, and reject missing samples before evaluating their values.
Add fault cases for a missing entire secondary probe and missing required
initial samples. This is enforcement of the existing contract; no tolerance
revision is needed.

This finding concerns acceptance completeness, not a demonstrated field or
shielding error: the actual retained records include both probes, and the
region-maxima checks continue to cover shielding independently.

### R3 resolution — 2026-09-22

Status: **fixed** as recommended, under MAT-01 specification revision 1.4 and
D022, in two layers.

- The structural audit compares the recorded `(component, index)` key set
  rather than a row count: identical at every state, and for a source case
  exactly the `Ez` edges the artifact's own `probe_indices` declares. The rule
  is a pure function (`probe_coverage`) over the per-state key sets, so its
  faults are injected without fabricating an artifact directory.
- Because that rule compares an artifact with its own declaration, the V04-C
  reduction takes the recommended route for C2/C3: the specification audit
  derives the probe pairs from the fixture — `(10,12,16)`/`(8,10,12)` and
  `(1,1,1)`/`(9,11,13)`, with both interior edges confirmed strictly inside the
  shell and unmasked — and the reduction requires the declared and the recorded
  set to equal them. `source_probe_checks` now takes the prescribed edges as
  arguments and requires every sample it reads to be present; no defaulting
  lookup remains.

Re-running this review's own `recheck-probe-completeness.py` after the fix, the
mutated copies are rejected by `audit_closed` with `recorded probes differ from
the prescribed indices`, and the reduction reports `4097` of `8194` prescribed
samples with both absent states named, for both driven cases. That re-run
regenerated `signoff-missing-probe/result.json` with the post-fix outcome; the
pre-fix `pass` it held is preserved in the finding above and in the fix's own
copy at `build/evidence/MAT-02/review-missing-probe/`. The unmodified retained
records pass unchanged, and re-analysis of `build/evidence/MAT-02/run1`

source fingerprint stays `706af2e4…`. Not repeated: a full physical re-run of
